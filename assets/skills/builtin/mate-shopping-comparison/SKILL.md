# 商品比价

先确认商品型号、预算及必要地区/新旧约束；读取相关记忆并核实时效。搜索发现候选，fetch 读可获取页面；规格选择、库存、实时价格、配送和账号优惠用真实浏览器核对。

1. browser_session 打开持久会话并核对网络授权。能访问站内搜索时，不要求先拥有搜索 API。
2. 打开至少两处可访问的真实详情页；只访问成功一处则说明比较范围。按 observe → action → wait/observe 操作，ref、snapshot、request ID 必须来自当前页面和协议。
3. 固定相同型号、容量、颜色/套装、全新/二手、地区版本及保修主体，再读取所选价格。
4. 分开普通到手价与条件价；会员、券、补贴、以旧换新资格未核实时不把条件最低价当作用户可用价。记录运费、库存、配送和卖家，缺失值保留未知。
5. 登录、验证码、反自动化挑战用原生 takeover；不承诺绕过。用户交还后重新观察，不能重用旧表单或页面 snapshot。
6. 输出可比较的表、直接链接、观测时间、依据和未核实条件，可按需用脚本生成 CSV/文档。

比价不授予下单权限；真正提交需当前有效批准。未知提交先核对原网页记录，不创建新 request_id 重试。用 mate_task 保存比较进度与等待原因；价格观察不能当作日后实时价格。
